# 智能记忆子页

## 目标与适用范围

「设置 › 智能 › 记忆」用于查看、搜索、新建、编辑、替换、启停与删除 AI 记忆。它是独立的侧栏子页，原审计页里的「记忆复核」区块由它取代，审计页只保留用量与日志。

记忆的注入规则不变：

- 会被注入的只有两种：`global` 范围的记忆，以及 `session` 范围且来源会话与当前会话一致的记忆；
- 每次最多注入 5 条，每条注入的是不超过 240 字的摘要。

页面如实标出哪些记忆会生效、哪些不会，不改变注入行为。

## 路由与导航

- 设置分类 key 为 `memory`，路径 `/setting/intelligence/memory`，页面文件为 `views/base/intelligence/IntelligenceMemoryPage.vue`；在路由的 `childLoaders` 中注册，路由名 `router.intelligenceMemory`。
- 侧栏图标 `i-ri-brain-line` 进入 UnoCSS safelist，不能渲染成空框。
- 不标 beta 或 advanced。
- 有侧栏图标的子页不再出现在智能页的入口行。
- 侧栏「塔芙智能」组的顺序为：智能 / 模型渠道 / 语音输入 / 技能 / MCP / 记忆。
- 智能页入口描述 `settingsIntelligenceHub.memoryDesc` 与审计描述 `auditDesc` 用词统一为「记忆」。

## 主从布局

页面使用 `SettingsPage` 的 split 布局。

左栏：

- 搜索：服务端搜索，300 ms 防抖；
- 筛选：类型、范围、状态三项，用 TuffEx 控件；
- 列表：每行显示摘要、类型 · 范围、停用标记、「暂不生效」标记；
- 分页：切换搜索或筛选条件时回到第一页；
- 底部：「新建记忆」。

右栏：

- 未选中时显示空态。
- 选中时显示详情：
  - 全文；
  - 注入说明：模型看到的是摘要，以及该范围是否生效；
  - 来源与审计字段；
  - 启停、编辑、删除。
- 编辑器流程：先评估，再在保存、替换、忽略中选择。

规则：

- 新建记忆的默认范围为「全局」，默认类型为「偏好」。
- 「会话 / 工作区 / 项目」范围在选择处标「暂不生效」，已有的不生效记忆在列表与详情里同样标出。生效判断与主进程注入规则使用同一套规则。
- 删除前用 TuffEx 底部确认框确认；删除后提示「后续回答不会再使用这条记忆」。
- 替换会生成新 id，替换成功后选中新 id。遇到 `MEMORY_REPLACE_CONFLICT` 时重载列表，并保持选中。
- 启停只更新当前行，不重排列表。
- KeepAlive 激活时刷新列表。
- 不显示「最近使用 / 使用次数」：这两个字段目前没有写入点，恒为空。
- 页面内用词统一为「记忆」，包括原「记忆审核」标题。
- 发给主进程的参数是纯数据，不含响应式代理。可选字段缺省时不发送 `null`。

### Scenario: 默认全局与不生效标记

验收：A20

WHEN 新建一条记忆，并查看范围为「会话 / 工作区 / 项目」的已有记忆。
THEN 新建默认范围为全局；不生效的范围在选择处、列表、详情都标「暂不生效」。
AND 删除要确认，删除后有提示；替换后选中新 id；冲突后重载并保持选中；离开再回来列表会刷新；原 `IntelligenceMemoryReview.test.ts` 的断言迁移到新组件后全部通过。
