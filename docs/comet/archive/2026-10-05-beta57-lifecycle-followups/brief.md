# 目标

修复用户截图列出的快捷键与本机代理生命周期遗留问题，连同已发现的应用快捷键占用预检不一致一起完成；通过真实宿主和独立验收后纳入本次 stage/master 收敛与 beta 发布。新修复不借用其他未完成的 Native change，不将其旧检查当作本次验收。

# 范围

- 系统快捷键启用状态与插件功能快捷键绑定的持久化及启动恢复。
- Pi 本机代理回合事件的最终完成判断与原生会话核对时序。
- 快捷键设置对话框、插件功能卡片和插件详情快捷键列表的实时状态刷新。
- 多个插件同时启动/停止时的合并注册行为回归。
- 应用快捷键占用预检与实际插件运行/注册判定一致。
- 更新 settings-shortcut-status 和 local-agent-cli 的完整目标规格；保留既有权限、默认值、错误码和原生会话兼容边界。

# 非目标

- 不改变快捷键默认组合、默认开关、macOS 抢焦点策略或冲突优先级；不迁移旧的坏录制值。
- 不扩展本机代理平台、协议、模型/工具权限、重试策略或原生会话格式。
- 不重做快捷键界面，不把插件快捷键塞进只列系统项的设置对话框。
- 不修改其他并发 change 的源码、Runtime 或验收结论，不关闭用户开发服务。
- 不删除分支、用户工作树、备份或个人配置；外层发布仅在所有纳入的功能验收后继续。

# 验收示例

- **A1｜系统快捷键持久化**：在隔离宿主中通过现有设置入口关闭一项系统快捷键，正常退出并重启后配置和状态仍为关闭、该项不注册；重新启用后再次重启仍为启用。录制输入框临时 disableAll/enableAll 不改用户保存的启用选择。
- **A2｜功能快捷键持久化**：通过插件功能卡片绑定、改绑和清除快捷键，每一步正常退出重启后配置与显示一致；所属插件停用/恢复不丢绑定，保存失败不显示成功。保留存储读取按值隔离，不能靠暴露可变内部数组修复。
- **A3｜Pi 最终完成时序**：agent_end 且 willRetry=true 时不进入原生会话核对、不提交最终 head、不提前完成任务；真正的 agent_settled 或不再重试的 agent_end 后按既有规则核对一次。失败、取消和旧/重复事件不产生迟到的成功完成。
- **A4｜设置页实时状态**：快捷键对话框保持打开，用户切换所属系统功能、关闭/启用记录或改变冲突状态时，其启用值、按键及状态文案自动更新，包括有效按键仍为 null 的状态原因变化；不必关闭重开，不覆盖正在保存的选择或被迟到响应回滚。
- **A5｜插件页实时状态**：插件功能卡片及插件详情快捷键列表保持打开，插件启停/崩溃/恢复、绑定变化或冲突变化后自动显示宿主最新值；切换插件/功能和卸载组件时不让旧请求或订阅污染当前页面，保留原来的失败回滚与权限边界。
- **A6｜多个插件合并注册**：至少两个不同插件在同一个既有合并窗口内从未运行变为运行，只发生一轮系统重新注册且两个插件的快捷键都可用；后续窗口仍会重新分类，ENABLED 与 ACTIVE 互转不额外注册，销毁模块会取消待处理批次。永久回归必须在移除合并守卫时失败，不用无状态翻转的重复事件凑覆盖。
- **A7｜应用绑定占用一致**：停用、缺失或未运行插件的 FEATURE/RENDERER 记录没有注册按键时，不阻止应用绑定该键、不弹虚假占用确认；实际运行的插件或系统绑定仍报告真实冲突，强制确认及保存失败回滚语义保持不变。
- **A8｜真实验收与保留契约**：相关现有回归、类型检查和定向 lint 通过；真实隔离 Electron 证明持久化/重启和宿主状态刷新，ego 验证可见界面，真实 Pi RPC/原生会话流程证明重试时序。原有 CLI 查找、只复用凭据、总开关默认关闭、原生会话缺失/冲突不可重试、插件 host-only 和回调权限契约不回退；测试和截图不代替实际操作结果。

# 约束与决定

- 用户明确要求截图四类问题一起处理；应用占用不一致已在本次会话明确提出，一并收尾。
- 当前主目录有多会话未提交改动且选中迁移 change；修复使用独立 /tmp 工作树，目标为本次独立集成分支，Git/index 由发布会话协调。
- 只复用既有快捷键变更事件与存储契约，不新增轮询、凭据读取、全局默认值覆盖或兼容别名。
- 永久测试由 Tester 编写；实现结束后统一执行最终检查，由新的只读 Verifier 判断所有验收项。
