# Tuff v2.4.14-beta.13 Release Notes

## Summary Notes

- Intelligence now uses a stable three-column provider workspace with complete channel, capability, prompt, and model entry points.
- The plugin store distinguishes installed, update-ready, and SDK-incompatible releases instead of offering an invalid install action.
- TuffEx adds Border Beam and Liquid visuals, with refined Badge width motion plus Button, Icon Button, and Select interactions.

## What's Changed

- Conversation sync now persists tombstones and migration state so history merges correctly after synchronization.
- Intelligence and settings surfaces use skeleton loading, preventing abrupt page swaps after full data resolution.
- Nexus component docs, live demos, and plugin Manifest projection were updated with the implementation.
