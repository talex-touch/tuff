# Tuff v2.4.15-beta.13 Release Notes

## Summary Notes

- Content indexing cap pause fix (A6): introduces a dedicated `index-full` pause state when the search index reaches its size cap, eliminating the 30-second retry loop on disks with ample free space and replacing misleading low-disk-space alerts in Settings.
- App index unstable-directory retry hardening (B1): extracts app bundle stability probing into a focused module, routes changing `.app` bundles into the bounded retry ladder, and tightens the `app-provider.ts` size ratchet.
- Home AI & UIKit Stage 2 convergence: brings `HomePage.vue` down to 781 lines (under the 800-line target) while aligning conversation controls onto `@talex-touch/intelligence-uikit`, and eliminates cold-transform timeout flakes in `HomePage.submit-race.test.ts`.
- `FileProvider` slimming (F1/F3): extracts pure record mapping and abortable async helpers, removes 4 unused public members, and lowers the `file-provider.ts` ratchet to 2,650 code lines.
- Nexus preview hydration, route-budget, and 3.0 Phase 0 probe updates: resolves SSR/CSR hydration mismatches and route fan-out across Nexus docs/auth/store surfaces, hardens preview evidence collection, and adds the 3.0 Phase 0 energy and memory baseline probe.

## What's Changed

- Search content-index cap vs. low-disk-space separation (A6): adds `'index-full'` to `FileIndexContentStorage['status']` and `projectContentStorage`; updates `FileProviderContentCapacityService` to classify `SEARCH_INDEX_RESERVE_REACHED`, `FILE_INDEX_STORAGE_FULL`, and plentiful-disk `SQLITE_FULL` failures as `'index-full'` so periodic 30s disk checks stop auto-resuming into a failure loop while preserving `'low-space'` for `ENOSPC`, disk-sourced errors, and `< 3 GiB` volumes; wires recovery hooks across capacity eviction, compaction, configuration cleanup, index reset/rebuild, content-disable cleanup, and index-size headroom drops while re-verifying OS disk space; updates `SettingFileIndex.vue` and localization strings to display distinct index-storage-full messaging.
- AppProvider stability extraction and bounded retry routing (B1): extracts `_waitForItemStable` and probe/settle timings into `app-provider-item-stability.ts` with `AbortSignal`-aware structured results; routes `changing` and non-missing stat `error` outcomes in `AppProvider.processAppPath` through the per-path-deduped bounded retry ladder (`2s/8s/30s` plus bounded dead-letter sweeps), keeps `missing` entries terminal, clears in-flight waits and timers on shutdown, and tightens the `app-provider.ts` module-size ratchet from `3,878` to `3,868`.
- Home AI Stage 2 modularization and UIKit convergence: upgrades `TxAiContextMeter`, `TxAiRunStatus`, and `TxAiMessageRail` in `@talex-touch/intelligence-uikit`, replaces duplicate local components with `HomeRunDock`, extracts focused composables and child SFCs to reduce `HomePage.vue` from 1,943 to 781 lines with zero production UI degradation, and isolates heavy paint/theme boundaries in tests to fix `HomePage.submit-race.test.ts` timeout flakes.
- `FileProvider` F1/F3 cleanup: extracts pure record mapping into `file-provider-record-mapper.ts`, consolidates repeated yield/abortable sleep helpers into `file-provider-async-utils.ts`, removes 4 unused public members, and lowers the `file-provider.ts` size ratchet from `2,790` to `2,650`.
- Nexus preview hydration, route budget, and 3.0 Phase 0 baseline harness: resolves SSR/CSR hydration mismatches, bfcache/service-worker issues, and route fan-out across Nexus docs, auth, store, and demo wrappers, and fixes collector bugs in `collect-deployed-preview-evidence.mjs`; adds `coreapp-energy-baseline-probe.mjs` with isolated profile safeguards, `powermetrics` matching, and unit tests for 3.0 Phase 0 energy/memory baselining.
