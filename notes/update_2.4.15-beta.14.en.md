# Tuff v2.4.15-beta.14 Release Notes

## Summary Notes

- Tuff 3.0 Phase 1 Search & Index Kernel process isolation (Slices 1 & 2): introduces a same-bundle Electron `utilityProcess` Search & Index Kernel host and Writer/Reader bridge behind `TUFF_SEARCH_KERNEL_UTILITY_PROCESS=1` (pure-Node cross-process RSS benchmark: Main peak RSS `-187.36 MiB` / `-71.94%`, workload delta `-91.28%`, zero latency regression; default remains `worker_threads` for safe beta soak).
- Tuff 3.0 Phase 3 idle renderer energy wins: pauses animations and timers across `TxBorderBeam`, `HomePet`, `HomeEmptyHead`/`TxMiko`, and `useAuth` whenever the window is blurred, hidden, `<KeepAlive>`-deactivated, reduced-motion, or in low-battery mode (0 Hz while backgrounded).
- File indexing symlink-root fix: canonicalizes symlinked watch roots and exclude paths in `file-scan-fd-backend.ts` so `fd` no longer drops files under symlinked roots on macOS.
- Generalized ACP & multi-CLI persistent runtime host: unifies persistent ACP, Codex, and Claude CLI agent execution in `CliAgentRuntimeHost` with optional Git worktree isolation and bounded diff inspection.
- TuffEx Pro FoldPage/FoldCorner & verification alignment: adds `@talex-touch/tuffex/pro` `TxFoldPage` and `TxFoldCorner` (`0.9.5`), aligns the Phase 0 energy baseline probe with packaged isolated launches, tightens Nexus deployed-preview evidence bounds, and syncs `beta.13` packaged acceptance docs.

## What's Changed

- Tuff 3.0 Phase 1 Search & Index Kernel host and Writer/Reader bridge (`#2279`, `#2280`): adds the pure-Node same-bundle `utilityProcess` host (`search-kernel-protocol.ts`, `search-kernel-process.ts`, `search-kernel-client.ts`, `out/main/search-kernel-process.js` with zero Electron GUI imports to preserve TCC/codesign identity) and bridges `SearchIndexWorkerClient` and `SearchIndexReadWorkerClient` via `search-kernel-worker-handlers.ts` and a shared `SearchKernelClient` singleton behind opt-in `TUFF_SEARCH_KERNEL_UTILITY_PROCESS=1`; preserves commit-receipt recovery, per-lane isolation, `SharedArrayBuffer` `Atomics.store` semantic cancellation, and graceful shutdown while keeping `worker_threads` as the default path for beta soak; adds `coreapp-search-kernel-rss-benchmark.mjs` measuring Main peak RSS `260.45 -> 73.09 MiB` (`-187.36 MiB` / `-71.94%`) and workload delta `+205.13 -> +17.89 MiB` (`-91.28%`) with parity verified and zero latency regression.
- Tuff 3.0 Phase 3 idle GPU and renderer CPU reduction (`#2281`): pauses `TxBorderBeam` CSS beam animations and its shared 30 fps `pulse-driver.ts` `requestAnimationFrame` loop, pauses `HomePet` (`usePetController.ts`/`HomePet.vue`) animation loops, timers, and `getBoundingClientRect()` polling, replaces hidden `TxMiko` double-mount in `HomeEmptyHead.vue` with `v-if` while pausing `TxMiko` timers/animations via `.is-paused`, and makes `useAuth` focus-prompt intervals lazy so backgrounded, blurred, hidden, `<KeepAlive>`-deactivated, reduced-motion, or `html[data-low-battery-motion='1']` states drop to 0 Hz with unchanged active-focus visuals.
- File indexing symlink-root canonicalization (`#2273`): resolves `canonicalRoot` via `fs.realpath` (with `path.resolve` fallback) in `file-scan-fd-backend.ts`, passes canonical roots to `fd` and traversal prune globs, maps ancestor and symlinked exclude paths across both resolved and canonical roots so macOS symlinked roots (such as `/var/folders/...`, `/tmp/...`, or user symlinked folders) no longer drop discovered files, and adds symlink-root regression tests.
- Generalized ACP & multi-CLI persistent runtime host with Git worktree isolation (`#2282`): adds generic `AcpClient`, persistent `CodexAppServerClient`, and bidirectional `ClaudeStreamClient` to `@talex-touch/tuff-intelligence` (keeping `OmpAcpClient` backward-compatible), integrates `CliAgentRuntimeHost` and driver resolution into `apps/core-app`, and introduces optional `GitWorktreeManager` lease-managed worktrees under `userData/ai-worktrees` with bounded diff reporting.
- TuffEx Pro FoldPage/FoldCorner, Phase 0 probe, Nexus evidence, and beta.13 reports (`#2276`, `#2275`, `#2272`, `#2274`, `#2278`): introduces `TxFoldPage` and `TxFoldCorner` (`0.9.5`) under `@talex-touch/tuffex/pro` with bilingual Nexus docs and demos; aligns `coreapp-energy-baseline-probe.mjs` with packaged isolated profile launches and real CoreBox CDP readiness; hardens Nexus deployed-preview evidence status derivation, route request budgets, API bounds, `--deployed-only` mode, and nested `omp` live-probe teardown; and records `v2.4.15-beta.13` packaged acceptance and Phase 0 baseline measurements.
