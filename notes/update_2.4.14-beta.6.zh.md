# Tuff v2.4.14-beta.6 更新说明

## 摘要

- CoreBox 恢复启动阶段隐藏预热和常驻复用，首次唤起不再临时创建窗口，隐藏超过旧超时后也不会重新加载。
- 应用壳、对话、AI 运行时、插件权限和跨平台搜索链路完成集中收口，日常交互与故障恢复更加稳定。
- Windows、macOS 和 Linux 的真实安装启动门禁进一步完善，macOS Beta 重新具备可安装、可公证、可更新的发布产物。
- 依赖、安全和发布治理持续加固，减少凭据暴露、原生模块遗漏和更新清单漂移风险。
- 已重新验证 Everything 官方 SDK，补齐 macOS 双架构依赖、双架构签名证据和隐私数据库启动竞态修复，恢复跨平台生产发布门禁。

## 变更内容

- CoreBox 前台模块初始化会等待隐藏窗口及渲染器完成创建；移除隐藏 60 秒后的正常销毁路径，同时保留异常销毁后的自愈重建。
- 首页会在首轮对话后生成短标题；应用壳、侧栏历史、设置和智能能力入口完成一致性收口。
- AI 运行时强化隔离调用、取消传播、流协议兼容与 MCP 服务退出识别；插件能力门禁和权限阻断原因统一收敛。
- 搜索与索引新增 Linux XDG 应用和图标发现、Everything 监听器清理、查询缓存指标及扫描背压验证，并补强 OCR、截图和原生插件生命周期。
- 修复 Sentry 渲染进程桥接、敏感通道参数、SQLite 配额、系统目录排除及多项跨层类型问题。
- 发布流水线补齐三平台打包后真实启动验证、macOS Developer ID 签名与公证、可识别的 DMG/ZIP 产物以及更新清单一致性检查。
- Everything SDK 的官方未版本化下载内容发生上游更新；本版本在核对官方来源、归档结构和双端 SHA-256 后更新固定校验和，仍保持不匹配即拒绝安装。
- PNPM 现在会在 arm64 macOS 发布机上同时安装 arm64 与 x64 可选二进制，确保双架构 LibSQL 和 esbuild 运行时均能进入签名产物。
- 隐私生命周期改用调用时解析的辅助数据库客户端：辅助库后台初始化期间安全回落主库，初始化完成后自动切换，不再因启动顺序竞态阻断 Windows 主进程。
- macOS 发布签名门禁现在逐一验证 arm64 与 x64 应用包，并把两份 codesign、Gatekeeper、公证和 TeamIdentifier 结果聚合为单一发布证据，不再把正确的双架构输出误判为失败。
