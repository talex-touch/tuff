# Tuff v2.4.14-beta.40 更新说明

## 摘要

- 新增文件夹项目：把一个已有目录当作一个项目，在该目录下运行本地 AI CLI，并跨任务、终端、面板关闭与应用重启续接原生会话，不复制、不重放供应商记录。
- 语音供应商改为云端下发的签名包：识别端点、模型列表与限额可由 Nexus 更新而无需发版；下载内容只是声明式参数，不含任何可执行代码或凭据，且需登录后才会拉取。
- 技能库改为直接读取机器上已安装的 Codex、Claude Code 等 Agent 目录，不再需要导入副本，磁盘上的改动下一轮对话即生效。
- 管理后台迁出 `/dashboard`，以独立 `/admin` 布局与轨道式导航呈现。
- 新增 TuffEx 组件：`TxIconMorph` 图标形变与 `TxIconPicker` 图标选择器；模型渠道可自选图标，同一适配器下的多个渠道不再长得一样。

## 变更内容

- 项目与会话：新增项目元数据与本地会话指针（SQLite），供应商记录仍留在供应商侧；续接前校验会话指针、实时能力与进程级租约，缺失、冲突、占用或不支持时一律失败关闭，绝不静默新建会话；归档项目保留会话并可恢复，"忘记"只删除 Tuff 的指针。
- 语音：签名包经固定 RSA 信任根校验，AES-256-GCM 信封仅用于传输与落盘保密；包内限额只能收紧本地硬上限；无激活包时内置 Nexus 路由照常工作。未登录时状态与本地回滚仍可用，但远程检查会以 `CATALOG_AUTH_REQUIRED` 拒绝且不产生任何网络请求。语音输入默认关闭，激活包不会改变该开关。
- 语音识别：新增带鉴权的 Qwen ASR 转发通道；修正现代 Qwen 响应体的解析；Workers 环境下显式绑定 `fetch`。
- 智能设置：能力提示词改为 900 ms 防抖自动保存，并在切换能力前冲刷，切走不再丢失未保存的编辑；写入按能力 id 定向，避免竞态把一个能力的提示词写到另一个上。
- 工作流页面移入开发者模式：路由同样带 `requiresAdvanced`，直接访问 URL 也不可达，而非仅从导航里隐藏。
- 界面：抽屉插槽内容延迟到首次打开才渲染；修复关闭状态的抽屉在窗口边缘留下暗带；数字输入框不再显示原生上下箭头；独立加载态统一用 `TxSpinner`，按钮加载态改用 `TxButton` 自带实现。
- 修复：复制的预览历史现在会被持久化；`PI_CLI_PROVIDER_ID` 经类型桶正确转发（此前 `export type *` 只带类型，该常量在渲染进程不可达）；图标选择器演示改用应用实际安装的图标集，此前渲染为空白方块。
