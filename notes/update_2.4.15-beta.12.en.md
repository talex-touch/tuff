# Tuff v2.4.15-beta.12 Release Notes

## Summary Notes

- Search index storage cleanup and runtime reliability fixes: retires unused keyword and metadata indexes, purges unread extension records and orphan or stale-model file embeddings, and fixes permanent `SQLITE_BUSY` error latching, post-query quit timeouts, and unthrottled maintenance retries.
- OMP CLI runtime host wiring: connects `profile:cli:omp` to the ACP-backed `OmpAgentRuntimeHost` with active MCP server configuration bridging and live text/reasoning delta streaming in conversation workspaces.
- Desktop dialog unification and lifecycle hardening: removes the final 4 legacy CoreApp dialog wrappers in favor of TuffEx dialogs, fixing stacked `#app` blur snapshots, inline style preservation, re-entrant button clicks, and external unregister container cleanup.
- Nexus SSR Worker bundle optimization and CI budget gate: trims unreachable demo and asset entries from `client.precomputed.mjs` and excludes charts from the SSR Worker, cutting Worker executable gzip size to 2.35 MiB with blocking CI budget verification.
- Dependencies and CI security baseline updates: upgrades `vue-router` to `^5.5.0`, `@electron/asar` to `^4.3.2`, macOS native `objc2` to `=0.6.5`, and safe Cargo, ESLint, and GitHub Actions dependencies, alongside renewed audit allowlists and waivers.

## What's Changed

- Search index storage cleanup and preflight coverage: stops creating and asynchronously drops zero-caller keyword and metadata SQLite indexes while covering `search_keyword_postings` in migration preflight and split-topology checks; stops writing unread `file_extensions.keywords` rows, cleans legacy unread rows plus orphan and stale-model file embeddings in bounded batches during boot maintenance, and enforces fail-closed split-writer routing during file index cleanup.
- Search runtime reliability improvements: treats transient `SQLITE_BUSY` scan failures as retryable degraded runs instead of latching file indexing in a permanent error state, switches `core-box:search:query` pushes to owner-directed one-way notifications to eliminate 8-second `before-quit` timeouts after queries, and adds exponential failure backoff to `IndexMaintenanceRunner`.
- `OmpAgentRuntimeHost` wiring for `profile:cli:omp`: routes `profile:cli:omp` through `OmpAgentRuntimeHost` and `OmpAcpClient` in `AiCliOrchestrator`, bridging active read-only MCP server configs, streaming live text and reasoning deltas in conversation workspace runs, and enforcing timeout/cancellation/interruption handling while preserving scheduler-decides-executor isolation.
- Legacy CoreApp dialog removal and TuffEx lifecycle hardening: deletes the remaining `TBlowDialog`, `TBottomDialog`, `TPopperDialog`, and `TouchTip` wrappers onto `@talex-touch/tuffex/dialog`; ref-counts `#app` blur snapshots across stacked `TxBlowDialog` instances while preserving unrelated inline styles, guards dialog button actions against re-entrant clicks and stuck loading states, clears timers on unmount, and removes DOM containers when `DialogManager` unregisters dialogs externally.
- Nexus Cloudflare SSR Worker bundle reduction and CI enforcement: parses and re-serializes `client.precomputed.mjs` to strip unreachable demo SFC and static asset keys, moves `@talex-touch/tuffex/charts` behind `import.meta.server`-guarded async boundaries, brings Worker executable gzip size down to 2.35 MiB (under the 2.70 MiB budget), and enforces the bundle budget check in CI.
- Dependency upgrades and CI hygiene: bumps `vue-router` to `^5.5.0` across apps and plugins, `@electron/asar` to `^4.3.2`, `objc2` to `=0.6.5` across macOS native crates, and safe Cargo (`napi`, `serde_json`, `tokio`) and `@electron-toolkit/eslint-config-prettier` updates; renews the production Electron audit allowlist and `json-formatter` waivers, bumps GitHub Actions versions, and adds package-level lint scripts for `apps/tuff-analyse`.
