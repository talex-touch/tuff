# Tuff v2.4.15-beta.10 更新说明

## 摘要

- 本地 AI CLI 版本探测收敛：应用退出时统一终止仍在运行的版本探测进程，为单次探测施加退出与强制结束超时，并禁止探测期间触发 mise 自动安装，消除孤儿进程堆积导致的高负载。
- 生产依赖安全升级：统一升级 Vue 3.5.45、sharp 等核心生产依赖以修复已知安全通告，同时保持构建与服务端工具链兼容稳定。
- 组件库与 Nexus 站点体验修复：升级 Tuffex 至 0.9.4，修复单选指示器在容器宽度变化时的越界偏移、文档侧栏首屏样式跳动，以及更新页水合切语言时短暂暴露原始翻译键的问题。
- 发版与说明同步链路加固：将 macOS 双架构签名公证超时放宽至 90 分钟，新增独立的线上发布说明同步工作流，并在 Markdown 渲染失败时立即阻断发布同步。

## 变更内容

- 本地 AI CLI 可执行文件版本探测改由受管子进程跟踪：5 秒超时后先发送 SIGTERM、1 秒宽限期后发送 SIGKILL；在退出前置清理（BEFORE_QUIT_STOP_WATCHERS）与模块销毁时终止全部在途探测，且退出启动后不再拉起新探测。
- 同一可执行路径共享在途版本探测进程，手动刷新时仅清空已缓存结果而不重复派生进程；探测环境固定注入 MISE_AUTO_INSTALL=false 与 MISE_NOT_FOUND_AUTO_INSTALL=false，防止缺失工具版本时在后台联网安装。
- 升级工作区生产依赖（Vue 家族收敛至 3.5.45 并更新相关安全补丁版本），保留 simple-git 3.x 兼容边界并同步更新生产审计白名单说明。
- 发布并接入 @talex-touch/tuffex 0.9.4：TxRadioGroup 按钮指示器改用 ResizeObserver 监听分组容器尺寸并在动画途中动态重算目标位置；Nexus 文档页首屏核心样式纳入 TxRadioGroup.css，消除侧栏切换控件的高度跳变。
- 修复 Nexus 客户端水合阶段的语言预加载策略：仅对服务端已内联的当前语言跳过等待，切换到其他偏好语言时等待目标语言包合并完成，避免导航栏与更新页出现 nav.store 等未翻译键名。
- 发布构建矩阵为 macOS 任务单独设置 90 分钟超时预算；新增 sync-nexus-release-notes 工作流支持按标签单独回写并回读校验双语说明，并为 Markdown 渲染请求启用严格 HTTP 错误中断。
