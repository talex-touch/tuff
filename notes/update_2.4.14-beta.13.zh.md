# Tuff v2.4.14-beta.13 更新说明

## 摘要

- 智能页改为稳定的三栏供应商工作台，并补齐渠道、能力、提示词和模型入口。
- 插件商店现在识别已安装、可更新与 SDK 不兼容状态，避免把不可安装的版本显示为“安装”。
- TuffEx 增加 Border Beam 与 Liquid 视觉组件；Badge 数值宽度、Button、Icon Button 与 Select 交互同步优化。

## 变更内容

- 对话同步增加墓碑与迁移状态，历史记录可在同步后正确合并。
- 智能与设置页面接入骨架加载，页面切换不再等待完整数据后突兀出现。
- Nexus 组件文档、交互示例及插件 Manifest 投影随实现更新。
