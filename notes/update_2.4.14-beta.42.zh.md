# Tuff v2.4.14-beta.42 更新说明

## 摘要

- 云端语音输入恢复可用：Nexus 签名语音路由现在会正确进入 `audio.asr`，不再因运行时能力缺失持续显示“不可用”。
- 语音模型目录与云端听写彻底解耦：目录超时、登录、上游故障和校验失败分别提示，且会明确说明本机模型目录故障不影响云端听写。
- 主窗口交互补强：新增命令面板、组合快捷键与按键提示；首页输入框在空白时显示引导光束，并移除重复项目徽标和多余命令窗口入口。
- TuffEx 与 Nexus 文档升级：DataTable 支持行展开，底部对话框重建为操作表单式 Bottom Sheet，组件文档统一为 Usage / API Reference 结构。
- 稳定性继续收口：修复冷启动 IPC 早于处理器注册导致的空状态，退出时先取消索引扫描再排空会话，Nexus dev 增加 OOM 监督与 Miniflare 正确释放。

## 变更内容

- 语音路由：`tuff-nexus-default` 仅在运行时投影 `audio.asr`，保留持久配置和共享 Resolver 的原有边界；真实默认 Provider、签名 Pack 与 buffered adapter 的整条链路已有回归覆盖。
- 本机模型目录：Descriptor 改为有界并发读取，保持目录顺序；同来源并发请求只构建一次，只缓存完整成功结果，并给单请求与整轮构建设置截止时间。
- 语音错误契约：新增稳定的认证、超时、上游不可用、目录无效和通用不可用错误码；主进程继续隐藏内部 URL、摘要和异常细节，Renderer 不再匹配错误文本。
- 语音设置：更名为“本机语音模型”，按云端 / 本地 / 混合来源解释目录故障；远程目录失败时，已安装模型仍可查看、使用和移除。
- 主窗口：命令目录统一拥有命令 ID、分组、图标与快捷键；只有已注册处理器的命令才会出现。Shell 顶栏移除重复命令入口，空白首页聚焦唯一输入动作。
- TuffEx：表格行展开支持受控与非受控状态、不可展开行和固定列偏移；Bottom Sheet 使用标题、关闭按钮与整行操作，仅危险操作保留错误色。
- 搜索与启动：初始化期间提前到达的 IPC 请求会延迟并在运行时就绪后重放；索引退出顺序、源级 Watch 诊断与全量扫描资源边界进一步修正。
- Nexus 开发：dev server 由监督器托管，限制长期热重载的堆增长；修复 Miniflare / workerd 在 Reload 后未释放的问题。
- 工程脚本：根脚本由 79 项收敛为 34 项，静态门禁、应用构建、版本和发布说明统一由参数化调度器接管，CI 与文档同步切换到新入口。
- 依赖维护：更新 Pi Agent Core、MCP SDK、pinyin-pro、JSZip、Nuxt DevTools 与 napi-rs 相关依赖。
