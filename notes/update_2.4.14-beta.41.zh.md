# Tuff v2.4.14-beta.41 更新说明

## 摘要

- 新增本地 MCP 服务：Tuff 把自己的工具以 MCP 暴露给本机其他 Agent（Codex、Claude Code 等），并在设置页按工具逐个授权，默认全关。
- 端侧语音识别可用：新增 sherpa-onnx 本地引擎，作为快速且自带标点的一档，与云端渠道并列可选，识别不再必须联网。
- 划词改口：选中文本后说一句指令即可按口令改写，不必只在光标处插入听写结果。
- 本地 AI CLI 收口：omp、Codex、Claude 的模型发现、选择指示与运行路径补全，启动时如实上报家族。
- TuffEx 补齐 Beautiful UI 差距：新增 Flowchart、ToastPanel、AgentScreen 与 UI 音效层，StatusBadge 改为标准 chip，新增 TxSensitiveInput 与 TxModeChip。
- 搜索索引写入融合：文件持久化与 FTS 写入合为一条写入链，检索结果与磁盘状态不再各写一份，语义检索也补上了真正的写入方。

## 变更内容

- 本地 MCP：只监听本机回环；工具授权按会话生效且可随时收回；未授权的调用失败关闭，不回落内置能力。
- 语音：端侧引擎与云端渠道共用同一 provider 契约，切换渠道不改变听写入口；识别语言收窄到该模型实际声明的范围，不再用不支持的语言发起请求。
- 语音度量：供应商往返时间与端到端时长分开统计、各自按自己的样本取平均；识别度量进入分析。
- 语音设置：已安装模型折叠为一行“更多模型”；识别详情改为面板与翻转对话框；识别记录表在存储视图可见。
- 本地 AI CLI：三个家族的模型目录与选择状态分别呈现；未写入的绑定不会被报告为已保存；本地 CLI 供应商遵守各自的书面契约。
- 应用索引：从只读列表变为管理界面，别名的写入改为单飞并校验确实落盘，用量按扫描时持久化的身份解析。
- 文件预览：可用系统中任意应用打开（不再仅默认应用），展示尺寸与应用来源；默认应用查询失败会如实报告失败。
- 快捷键：可把全局快捷键绑定到任意插件功能。
- 性能：全量扫描不再过度节流并限制图标提取；诊断轮询用到的 stat 查询建立索引；扫描进度不再每 tick 重取源诊断；搜索索引完整性检查不再卡住启动。
- Nexus 文档站：新增页面级模板，画廊样例可重放，更新页可筛选；Pages 返回真实 404 与静态重定向，边缘缓存窗口与区域 Cache Rule 对齐。
- 界面：暗色语义填充改为向表面混色；抽屉插槽内容延迟到首次打开才渲染；markdown 工具栏图标改用 Carbon 元数据；引导页的点击可以穿过窗口拖拽区。
