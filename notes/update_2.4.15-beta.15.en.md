# Tuff v2.4.15-beta.15 Release Notes

## Summary Notes

- Herdr Space, docked workspace panels, and unified multi-CLI AI: integrates the `herdr-core` runtime plane, Space-scoped project/browser tabs, docked file tree, Git diffs, side browser, terminal drawer, Pi mid-turn steering, and default-on startup auto-recovery while preserving scheduler-decides-executor isolation.
- Workspace Canvas editing and voice dictation history retry: adds atomic sandboxed file editing with conflict recovery and persistent selection highlights in `WorkspaceFileViewer`, plus per-row voice history audio re-transcription, configurable retention TTL (`7d` / `30d` / `off`), daily grouping, source filters, and custom dictionary auto-learning.
- Zero-execution npm plugin ecosystem and Browser Workspace polish: introduces canonical npm plugin installation and packaging with 12 new official plugins, upgrades Store discovery and SVG icon sanitization, integrates Home/Herdr stage controls into the top tab strip, and adds Browser Workspace Phase 2 history shortcuts (`Alt+ArrowLeft/Right`, `Cmd+[/]`).
- Tuff 3.0 Phase 2 idle budget and cross-platform hardening: adds `IdleBudgetCoordinator` to pause background polling loops when hidden or suspended, hardens Windows Everything/PowerShell fallbacks, Ubuntu 24.04 FUSE3/AppArmor packaging, and macOS archive safety, and prevents `install-app-deps` from stripping native screenshot/OCR binaries (packaged idle soak and Windows/Linux hardware verification remain open).
- TDS design system and TuffEx multi-framework upgrades: lands TDS M0–M3 tokens, OpenUI, device frames, and L1 design canvas alongside TuffEx multi-framework packages (`tuffex-core`, `tuffex-react`, `tuffex-wc`), `TxMatrixLoader` (`0.9.6`), `TxFlowchart` effects, `TxAvatarEditor`, and Retina/Kitty inline terminal images.
- Security, atomic data lifecycle, and CI/dependency hygiene: enforces scoped renderer CSP via response headers, upgrades Nexus to Nuxt 4.5.2 / unhead 3, lands atomic idempotent telemetry/privacy/credits writes (Preview/production soak remains open), hardens CI closing-keyword and Rust toolchain gates, and updates workspace dependencies.

## What's Changed

- Herdr Space, unified multi-CLI runtime, and startup auto-recovery (`#2286`, `#2288`–`#2292`, `#2294`–`#2296`, `#2308`, `#2311`–`#2314`): integrates the `herdr-core` runtime plane (`betaFeatures.herdrRuntime`), declarative ACP multi-CLI drivers, ToolGateway herdr tools, Pi mid-turn steering, unified model/scheduler composer pill, OpenAI reasoning/usage streaming with provider timeout handling, and default-on startup recovery (`conversation.autoResumeOnStartup`) for interrupted conversations, orchestrator runs, external CLIs, and crashed windows; adds Herdr Space UX, temporary spaces, Space-scoped project/browser tab groups, docked right side panel (workspace file tree, side browser, terminal runner), and Git branch/remote/per-commit diff views.
- Workspace Canvas editing and `WorkspaceFileViewer` integration (`#2330`, `#2340`): adds atomic sandboxed `writeWorkspaceFile` with per-path locking, `mtimeMs` conflict checks, and conflict compare/reload/overwrite recovery; wires persistent CSS Custom Highlight (`registerSelectionHighlight`) while compose/comment docks are open, replaces the dock spinner with `TxSpinner`, and upgrades post-edit confirmation with a prismatic scanline curtain reveal.
- Voice dictation history retry, retention TTL, grouping, and custom dictionary (`#2339`): implements per-history-row re-transcription from retained local WAV audio with canonical containment checks and concurrent-retry deduplication, adds configurable `voiceInput.historyRetention` (`7d` / `30d` / `off`, default `30d`) with startup and 6-hour cleanup, adds daily grouping and `All` / `Dictate` / `Ask` source filters, and adds custom dictionary CRUD with edit auto-learning (packaged/device verification and Bailian async `vocabulary_id` remain tracked under `#1880`).
- Zero-execution npm plugin ecosystem and Store improvements (`#2287`, `#2297`, `#2309`): adds the canonical npm plugin contract, atomic install/provenance verification, CLI dual-publish packaging, audits 29 official plugins, and ships 12 new utility/developer plugins (`touch-color-studio`, `touch-diagram-sketch`, `touch-svg-craft`, `touch-api-lens`, `touch-markdown-craft`, `touch-pomodoro-zen`, `touch-calc-pad`, `touch-world-time`, `touch-totp-vault`, `touch-regex-lab`, `touch-cron-craft`, `touch-docs-atlas`); upgrades Store source editing, GitHub topic discovery, multi-keyword NPM search, and SVG plugin icon sanitization with fallback resolution.
- Modern Browser Workspace polish, history shortcuts, and default-on clarification (`#2283`, `#2312`, `#2317`, `#2334`): restyles browser tabs as G2 capsules with page transitions, scopes workspace tabs per Space, consolidates Home and Herdr stage actions into the top `BrowserTabStrip`, and adds Phase 2 back/forward keyboard shortcuts (`Alt+ArrowLeft/Right` and macOS `Cmd+[/]`); clarifies that `betaFeatures.browserWorkspace` has been enabled by default since `73e6a1b8c` (superseding the historical "off by default" note in `v2.4.15-beta.9`) and remains manually toggleable in Settings.
- Tuff 3.0 Phase 2 idle budget coordinator (`#2322`): introduces `IdleBudgetCoordinator` (`active` / `background-hidden` / `system-suspended`) linked to `powerMonitor` and a global `PollingService` pressure channel to pause background system sampling, file/capacity polls, download, error-log, network, and OCR intervals while hidden or suspended; packaged 10-minute idle soak and Phase 0 Metric 2 (`sudo powermetrics`) verification remain open.
- Cross-platform packaging, R3 memory benchmark, Windows fallbacks, and Ubuntu 24.04 hardening (`#2318`, `#2319`, `#2325`, `#2333`): prevents macOS dual-arch archive overwrite and enforces `chokidar-fsevents` in packaged runtime validation; validates Everything SDK readiness and passes the hosted `windows-2022` Everything Production Gate (`26/26`); adds a real-libSQL `25k`/`100k` paged reconciliation memory benchmark (`parity=OK`, bounded heap/FDs), Windows PowerShell error classification with `reg.exe` fallbacks and typed degraded diagnostics, Ubuntu 24.04 static FUSE3 AppImage (`1.0.3`) + `.deb` AppArmor `userns` profile + launch failure classification, and preserves `tuff_native_screenshot.node` and `tuff-native-ocr(.exe)` across `install-app-deps` (Windows/Linux packaged native screenshot capture, `#308` strict Windows acceptance manifest backfill, and physical Intel x64 Mac verification remain open).
- TDS design system (`M0`–`M3`) and TuffEx / UIKit / Nexus enhancements (`#2293`, `#2298`, `#2310`, `#2315`, `#2316`, `#2326`, `#2327`, `#2337`): ships single-source TDS tokens, fine-grained OpenUI, `TdsDeviceFrame`, static/offscreen DOM lint probes, `TdsDesignCanvas`, mockup export, and 3-layer declarative theme packs; introduces `tuffex-core`, `tuffex-react`, and `tuffex-wc` with a Nexus multi-framework switcher; adds `TxMatrixLoader` (`0.9.6`), `TxFlowchart` curve routing/pulses/halos/HUD, editable `TxAvatarEditor` (with crop/rotate/color, video/GIF clip extraction, pixel-budget & opt-in `allowRemoteSource` gating), `registerSelectionHighlight`, `TxToolCallCard` `autoExpandDelayMs`, runnable code blocks, and Retina HiDPI / Kitty Graphics Protocol inline images in `TxTerminal`.
- Renderer CSP enforcement, Nuxt 4.5.2 upgrade, and atomic data lifecycle (`#2320`, `#2321`, `#2332`, `#2334`): replaces report-only CSP with response-header enforcement scoped to `file:///*` and `modules/renderer-override`; upgrades Nexus to Nuxt 4.5.2 / unhead 3 (clearing 9 resolved Critical/High production-audit allowlist entries) and aligns Admin Console `codes.vue` onto a route-level redirect with zero `KNOWN_ORPHANS`; enforces deterministic `X-Idempotency-Key` outbox delivery, single-`db.batch()` telemetry/governance/privacy deletion with a 30-day finalizer, and atomic Credits adjustments (Preview/production soak verification remains open under `#1788`).
- CLI discovery, CI governance guards, and dependency updates (`#2328`, `#2329`, `#2331`, `#2335`, `#2336`, `#2299`–`#2307`): expands `tuff-cli doctor` executable discovery across version managers and local AI CLIs (`0.1.2`); pins the Rust CI toolchain (`1.100.0`) with a required `Protocol` aggregator gate; extends closing-keyword checks to PR titles and constituent commits, restores Nexus `check:demo-registry` and `audit:contrast:self-test` CI gates, allows Dependabot PRs targeting `master` in branch policy, and merges dependency updates (`@anthropic-ai/claude-agent-sdk`, `@codemirror/language`, `@codemirror/autocomplete`, `jdx/mise-action`, `cc`, `libc`, `napi`, `napi-derive`, `vitepress`).
