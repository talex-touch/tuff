# Tuff v2.4.14-beta.57 更新说明

## 摘要

- 移除语音输入浮球，语音输入只保留 Fn/Ctrl 唤起的听写胶囊。
- 内嵌终端统一使用 TxTerminal 与原生 PTY，会话支持输入、窗口调整和退出清理。
- CoreBox 推荐结合使用历史、时间和调用时的前台应用，前五项进入宫格；通过 Cmd+Tab 或 Dock 切换的应用也计入最近使用。
- 修复启动后首次唤起 CoreBox 无法输入；文件索引扫描与复制大图不再长时间卡住主线程。
- Home 输入工具条改用权限、模式和模型胶囊；本地 Agent、Skills 和 MCP 设置分开管理，修复 macOS 从 Dock 启动时的 CLI 检测。
- Nexus 管理台统一到 Admin Kit，首页与 TuffEx 文档重写；TuffEx 新增 Motion 能力，弹层默认不带箭头。

## 变更内容

- 删除语音输入浮球：按 Fn/Ctrl 直接出现底部听写胶囊，不再先闪出浮球；智能设置页移除「Assistant 悬浮入口」，已保存的浮球设置在加载时自动清理。
- 登录后默认开启语音听写（主动关闭过的除外）；语音服务端故障时提示服务不可用，不再报网络错误。
- 统一终端渲染、原生 PTY 会话、尺寸同步和所属窗口退出时的资源释放。
- 移除 CoreBox 顶部的本地 AI CLI 按钮，保留底层 Agent 能力。
- 修复启动后首次唤起 CoreBox 时后台预热的浮层抢走焦点、输入框无法输入；唤起时直接读取前台应用，推荐不再等待 AppleScript 查询。
- 推荐使用一条固定项优先的排序序列，文件、应用和内置入口均可进入前五项宫格。
- 结合昨日此时、常用时间和前台应用的真实已接受历史；显示独立原因，不用虚构常用项目补位。
- 跨异步查询、缓存和快捷执行保留最初调用来源，避免前台应用改变后错误归因。
- 通过 Cmd+Tab 或 Dock 切换到前台的应用也计入「最近使用」（macOS，无需额外权限）。
- Home 权限菜单在同一行确认完整访问；模式与 Agent 管理分层，模型弹层保留搜索、最近选择和能力配置。
- 修复弹层关闭、清空搜索、保存 Agent 与模型来源延迟加载时的焦点和滚动位置。
- 拆分 MCP 设置，按 Agent 命名发现的配置，并为 stdio 服务提供可用 PATH。
- 本地 CLI 检测兼容 macOS Dock 启动；PI-Desktop 可复用已有工作区，补齐重试和插件状态通知。
- 修复 macOS Option 改写字符后的物理按键记录，并持久化自定义快捷键。
- 接入 CoreBox 焦点诊断与脱敏错误遥测，保留已有焦点策略。
- 补齐应用索引启动健康状态，以及已恢复的闲时索引与维护调度约定。
- 文件索引修复对账写入失败；路径、扩展名和新增文件查询改用合适的索引，消除扫描期间的周期性卡顿；关闭内容索引后残留的文本会再次清理，并在空间允许时压缩索引文件。
- 复制大图时直接复用剪贴板中的 PNG 数据，不再在主线程重新编码；退出前先停止原生文件监听，避免退出过程中崩溃。
- 遥测开关移到通用设置页并统一授权，错误信息进一步脱敏，搜索指标不再发送到 Sentry；隐私导出补齐已执行的搜索记录（仅来源与时间）和前台应用表。
- 提示和弹层默认不显示箭头；指针从触发器移向悬停弹层时跨过空隙不会关闭弹层，并以安全三角保护移动路径，展开动画的回弹幅度受限。
- Nexus 管理台统一用户、激活码、更新、资源、评论、渠道、AI 概览和调用审计页面。
- 修复文档本地化链接、目录页、管理页面离场后的空白与按需文档交付。
- Nexus 首页重做，首屏展示真实 CoreBox；TuffEx 文档精简重写并补齐 API，安装命令可切换包管理器；服务端批量合并数据库读写并按日汇总遥测。
- TuffEx Motion 提供按钮、卡片展开、三维轮播、加载器、文字、物理、指针、滚动、开关和转场能力。
- TuffEx 新增 TxMorph 与可随时定位的弹簧；开关、滑块、折线、图标变形、复制按钮和分割按钮加入新的动效。
- Mono 图表进入 Data；复合指标、表单和 UI Kit 进入 Pro，中英文 API、导航、Gallery 和可运行示例同步。

## 已知限制

- Ghostty 渲染器尚未接入；本版本不能宣称提供原生 Ghostty 嵌入。
- 推荐来源的物理前台切换已在 macOS arm64 验证；Windows 和 Linux 未覆盖同等设备场景。
