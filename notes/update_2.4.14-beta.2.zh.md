# Tuff v2.4.14-beta.2 更新说明

## 摘要

- TuffEx 新增可感知尺寸变化的 ResizeBox，便于构建自适应组件和布局。
- Nexus 新增 ResizeBox 中英文文档与交互示例，API 与生命周期用法可直接验证。
- 本地 Nexus 开发和 GitHub 发版恢复流程更加稳定，失败后的定位与恢复更可靠。

## 变更内容

- 新增 `TxResizeBox`，可随内容或容器尺寸变化平滑调整外层尺寸，并提供明确的调整开始与结束事件。
- 新增 ResizeBox 双语组件文档、响应式交互演示、导航入口和完整 API 说明。
- 修复本地 Nexus 开发环境未加载 Cloudflare 运行时凭据时文档请求返回 500 的问题，同时保持远程环境严格校验。
- GitHub 发版流程现在可复用来源已校验的跨平台构建产物，从发布阶段失败中恢复而无需重复构建。
