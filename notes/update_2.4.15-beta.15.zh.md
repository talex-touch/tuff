# Tuff v2.4.15-beta.15 更新说明

## 摘要

- Herdr Space、工作区停靠面板与统一多 CLI AI：集成 `herdr-core` 运行平面、按 Space 隔离的项目/浏览器标签、右侧工作区文件树、Git 差异视图、内嵌浏览器、终端抽屉、Pi 轮中 steering 与默认开启的启动自动恢复，并继续严守“调度器决定执行器”隔离规则。
- 工作区画布编辑与语音转写历史重试：`WorkspaceFileViewer` 新增原子沙箱文件写入、冲突恢复与持久选区高亮；语音输入新增历史记录音频重转写、可配置保留时长（`7d` / `30d` / `off`）、按日分组、来源筛选与自定义词库自动学习。
- 零执行 npm 插件生态与浏览器工作区打磨：落地标准 npm 插件安装与双目标打包并新增 12 个官方插件，升级插件商店发现与 SVG 图标清洗，将 Home/Herdr 舞台控件整合至顶部标签栏，并补齐浏览器工作区 Phase 2 前进/后退快捷键（`Alt+ArrowLeft/Right`、`Cmd+[/]`）。
- Tuff 3.0 Phase 2 空闲预算与跨平台打包加固：新增 `IdleBudgetCoordinator` 在窗口隐藏或系统休眠时暂停后台轮询，加固 Windows Everything/PowerShell 回退、Ubuntu 24.04 FUSE3/AppArmor 打包与 macOS 归档防覆盖，并修复 `install-app-deps` 剥离原生截图/OCR 二进制的问题（打包空闲能耗长稳与 Windows/Linux 真机验收仍开放）。
- TDS 设计系统与 TuffEx 多框架及组件升级：落地 TDS M0–M3 单源令牌、OpenUI、设备画框与 L1 设计画布，同步交付 TuffEx 多框架包（`tuffex-core`、`tuffex-react`、`tuffex-wc`）、`TxMatrixLoader`（`0.9.6`）、`TxFlowchart` 动效、`TxAvatarEditor` 以及 Retina/Kitty 终端内联图像。
- 安全收紧、数据原子生命周期与 CI/依赖治理：主进程通过响应头强制执行渲染层 CSP，Nexus 升级至 Nuxt 4.5.2 / unhead 3，落地遥测/隐私删除/积分原子幂等写入（Preview/生产长稳验收仍开放），强化 CI 关闭关键字与 Rust 工具链门禁，并合入工作区依赖更新。

## 变更内容

- Herdr Space、统一多 CLI 运行时与启动自动恢复（`#2286`、`#2288`–`#2292`、`#2294`–`#2296`、`#2308`、`#2311`–`#2314`）：接入 `herdr-core` 运行平面（`betaFeatures.herdrRuntime`）、声明式 ACP 多 CLI 驱动、ToolGateway herdr 工具、Pi 轮中 steering、合并模型与调度器的输入框胶囊、OpenAI 推理/用量流式透出及供应商超时尊重，以及默认开启的启动自动恢复（`conversation.autoResumeOnStartup`，覆盖中断对话、编排任务、外部 CLI 与崩溃窗口自动重载）；落地 Herdr Space 体验、临时 Space、按 Space 隔离的项目与浏览器标签组、右侧停靠工作区面板（文件树、侧边浏览器、终端执行）与 Git 分支/远端/逐提交差异视图。
- 工作区画布编辑与 `WorkspaceFileViewer` 体验集成（`#2330`、`#2340`）：新增基于单路径串行锁、沙箱边界与 `mtimeMs` 校验的原子写入服务 `writeWorkspaceFile` 及未保存草稿冲突对比/重载/覆盖恢复；在画布编辑与评论浮层开启期间接入持久 CSS Custom Highlight（`registerSelectionHighlight`），以 `TxSpinner` 替换手写加载指示器，并升级编辑完成后的棱镜扫描揭示动效。
- 语音转写历史重试、保留时长、分组与自定义词库（`#2339`）：实现历史单行基于本地保留 WAV 音频的重新转写（含规范目录边界校验与并发重试去重），新增可配置 `voiceInput.historyRetention`（`7d` / `30d` / `off`，默认 `30d`）与启动后/每 6 小时自动清理，支持按日分组、`全部` / `听写` / `提问` 来源筛选，以及自定义词库增删改查与编辑自动学习（打包实机验收与百炼异步 `vocabulary_id` 仍在 `#1880` 持续跟进）。
- 零执行 npm 插件生态与插件商店升级（`#2287`、`#2297`、`#2309`）：建立标准 npm 插件契约、原子安装与来源校验、CLI 双目标打包能力，完成 29 个官方插件审计并新增 12 个实用与开发插件（`touch-color-studio`、`touch-diagram-sketch`、`touch-svg-craft`、`touch-api-lens`、`touch-markdown-craft`、`touch-pomodoro-zen`、`touch-calc-pad`、`touch-world-time`、`touch-totp-vault`、`touch-regex-lab`、`touch-cron-craft`、`touch-docs-atlas`）；升级商店源编辑器、GitHub topic 发现、NPM 多词检索以及缺失 SVG 插件图标清洗回退解析。
- 现代浏览器工作区打磨、历史快捷键与默认开启说明（`#2283`、`#2312`、`#2317`、`#2334`）：将浏览器标签重构为 G2 胶囊样式并补齐页面过渡，按 Space 隔离工作区标签，将 Home 与 Herdr 舞台右侧动作整合进顶部 `BrowserTabStrip`，并补齐 Phase 2 前进/后退快捷键（`Alt+ArrowLeft/Right` 与 macOS `Cmd+[/]`）；同时明示勘误：`betaFeatures.browserWorkspace` 自 `73e6a1b8c` 起已默认开启（含一次性迁移，替代历史 `v2.4.15-beta.9` 发布说明中的“默认关闭”旧措辞），并仍支持在设置中手动关闭。
- Tuff 3.0 Phase 2 空闲预算协调器（`#2322`）：新增 `IdleBudgetCoordinator`（`active` / `background-hidden` / `system-suspended` 三态状态机），联动 `powerMonitor` 与 `PollingService` 全局压力通道，在窗口后台隐藏或系统休眠锁屏时暂停系统采样、文件/容量状态、下载、错误日志、网络与 OCR 后台轮询；打包版 10 分钟空闲能耗长稳复测与 Phase 0 Metric 2（`sudo powermetrics`）仍保持开放。
- 跨平台打包、R3 内存基准、Windows 回退与 Ubuntu 24.04 加固（`#2318`、`#2319`、`#2325`、`#2333`）：修复 macOS 双架构归档覆盖并将 `chokidar-fsevents` 纳入跨平台打包运行时强制校验；校验 Everything SDK 运行时就绪并在托管 `windows-2022` 通过 Everything Production Gate（`26/26`）；新增真实 libSQL `25k`/`100k` 分页对账内存基准（`parity=OK`，堆内存与文件句柄有界）、Windows PowerShell 错误分类与 `reg.exe` 回退及类型化降级诊断、Ubuntu 24.04 静态 FUSE3 AppImage（`1.0.3`）+ `.deb` AppArmor `userns` 配置 + 启动失败分类，并在 `install-app-deps` 阶段保留 `tuff_native_screenshot.node` 与 `tuff-native-ocr(.exe)`（Windows/Linux 打包原生截图实机捕获、`#308` 严格 Windows acceptance manifest 回填与物理 Intel x64 Mac 验证仍保持开放）。
- TDS 设计系统（`M0`–`M3`）与 TuffEx / UIKit / Nexus 增强（`#2293`、`#2298`、`#2310`、`#2315`、`#2316`、`#2326`、`#2327`、`#2337`）：落地单源 TDS 令牌、细粒度 OpenUI、`TdsDeviceFrame`、静态与离屏 DOM 探针、`TdsDesignCanvas`、Mockup 导出与三层声明式主题包；新增 `tuffex-core`、`tuffex-react` 与 `tuffex-wc` 多框架包及 Nexus 框架切换器；交付 `TxMatrixLoader`（`0.9.6`）、`TxFlowchart` 曲线路由/脉冲/光晕/HUD、可编辑 `TxAvatarEditor`（支持裁剪/旋转/调色、视频与 GIF 片段提取、像素预算与默认关闭的 `allowRemoteSource` 远端门控）、`registerSelectionHighlight`、`TxToolCallCard` 延迟展开（`autoExpandDelayMs`）、可运行代码块与 `TxTerminal` Retina HiDPI / Kitty Graphics Protocol 内联图像。
