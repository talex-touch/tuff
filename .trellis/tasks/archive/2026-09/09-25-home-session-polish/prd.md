# 主页会话体验打磨：项目徽标 / 侧边栏 / 融合组件 / 发送分裂动画 / 个人助理推送

## Goal

把 Home（Tuff 智能主页）从「一个空输入框 + 聊天记录」打磨成像个人助理一样的首屏：空态不再有来路不明的元素，侧边栏能看清项目与对话的归属，发送一条消息时有「从输入框里分裂出去」的连贯手感，并且主页默认会主动给用户推送内容。

本任务是父任务：只持有需求来源、子任务映射、跨子任务验收与最终集成走查，本身不直接改代码。

## 已拍板的决策

- 2026-09-25：按 Trellis 走父任务 + 子任务，先出规划文档给老板过目再动手。
- 侧边栏方向：**项目文件夹化**——「项目」成为独立分区，每个项目是可折叠的文件夹行，当前项目自动展开并高亮；「新建项目」并入分区标题的 `+`；原「主页」分组改名「对话」。
- 融合特效落地方式：**新增路径型融合组件**。按 uiarc Dock 的思路自研：单条 SVG 路径 + 凹圆角 + 弹簧，无滤镜。uiarc 是付费组件库，只借鉴技术，不搬代码。
- 真实应用验证：**允许重启 `pnpm core:dev` 并带上远程调试端口**，用 CDP 在真实窗口里录帧、测掉帧；tuffex 组件在 nexus 文档站里用 ego-browser 验证。
- R5 推送（细节见 `09-25-home-assistant-push/prd.md`）：分两阶段（无历史 → 开场白 + 引导卡；有历史 → 「为你准备」推送）；开场白由模型个性化生成；居中英雄区布局；开场白发送后并入对话成为第一条。
- 侧边栏细节（见 `09-25-sidebar-project-folders/prd.md`）：点项目名进入项目、箭头折叠；默认折叠、当前项目自动展开、记住选择。
