# Home 开场白默认关闭，设置里可开

父任务：`09-25-home-session-polish`。

## 老板原话（2026-09-26，语音输入整理）

> 主页那个推荐，如果没有登录的话，默认不应该请求，不然会稀里糊涂就消耗用户的 AI 额度。或者说用户可以自己配置一下，你看着办。就是默认不应该启用。

## 背景

空白 Home 的开场白（`modules/home-push/opening.ts`）每次进入空白对话都会调一次模型（今天刚改成走输入框的路由，本机是 Claude / Codex CLI，一次约 14k prompt token）。用户没主动要求，却在后台花他的额度。「为你准备」卡片和模板开场白都是本地数据，不花钱。

## 要求

1. 新设置 `appSetting.tools.homeAiOpening`，**默认关**（旧档案没有这个字段也按关处理：只有显式 `true` 才开）。
2. 关着时：空白 Home 直接显示本地模板开场白，**不发任何模型请求**，也不回放缓存里的模型开场白；发送时模板不并入对话（与现在的模板行为一致）。
3. 开着时：保持现状（走输入框路由、2.5s 后模板顶着、30s 内写完整段替换、10 分钟同摘要复用）。
4. 设置入口：设置 ·「插件与工具」里和「自动上下文」同一组，一个开关，说明写清会消耗所选模型的额度、关着时用本地模板。
5. 文案进 zh-CN / en-US 语言包。

## 验收

- [x] 单测：关着时 `start` 显示模板、`sdk.stream` 调用次数为 0、`takeLead` 返回 null。
- [x] 真实窗口：默认进入空白 Home 只见模板，日志里没有新的 `Streaming capability: text.chat`；设置里打开后再进空白 Home，开场白恢复为模型写的；关掉恢复模板。
- [x] 包内 eslint / prettier、`vue-tsc -p tsconfig.web.json` 无新增错误。

## 不做

- 不区分登录与否（老板结论是「默认不应该启用」）；不改「为你准备」卡片。

## 结果（2026-09-26，`3b0b3485b`）

- 默认关：重载后进空白 Home，51ms 出模板，开发日志 0 次新的 `Streaming capability: text.chat`。
- 设置里打开：空白 Home 出骨架、2.5s 模板顶着，发出 1 次模型调用；关回后设置为关（老板的默认值已还原）。
- 单测 306 通过（含新增「关着时模板、零调用、缓存也不回放、每次启动时读开关」）；eslint / prettier 通过；`vue-tsc -p tsconfig.web.json`、`tsc -p tsconfig.node.json` 退出码 0。
