# 侧边栏项目文件夹化与选中态修正

父任务：`09-25-home-session-polish`（R2）

## Goal

侧边栏一眼能看清三件事：现在在哪（当前对话 / 当前项目只有一处高亮）、项目下面有哪些对话（项目是可折叠的文件夹）、不属于任何项目的对话在哪（「对话」分区）。

  - 每个项目是一行文件夹：展开 / 折叠箭头 + 文件夹图标 + 名称 + 悬停操作；展开后是它的对话与本机 AI 会话，缩进一级。

  - 原「主页」分组改名「对话」，放在「项目」之后。
  - 「新建对话」不再常亮。

## Requirements

1. **选中态唯一**（P1 / P4）：任何时刻侧边栏只有一处「当前」高亮。
   - 打开历史对话：该对话行高亮。
   - 某项目里的空白新对话：该项目行高亮。
   - 不属于项目的空白新对话：「新建对话」高亮。
2. **分区**（P2）：展开态侧边栏的对话区分成「项目」「对话」两个分区，顺序为 项目 → 对话 → 已归档项目（折叠开关，行为不变）。「对话」装不属于任何项目的对话（原「主页」分组）。
3. **项目行**（P3）：每个项目一行，结构为 [展开 / 折叠开关][文件夹图标][名称][`⋯` 菜单]。
   - 点名称：进入该项目的新对话（`enterConversation(project.id)`）。
   - 点开关：只折叠 / 展开，不导航；开关是真正的 `<button>`，带 `aria-expanded` 与可读标签。
   - 文件夹图标随展开状态切换（打开 / 合上）。
   - `⋯` 菜单项不变（新建对话 / 运行本机代理 / 发现本机会话 / 重命名 / 置顶 / 归档）；去掉与点名称重复的独立 `+` 按钮。
4. **嵌套**：展开后显示该项目的对话与本机 AI 会话（顺序与现在一致），缩进到项目名那一列；项目下暂无对话时显示一行弱化的提示，不再是虚线按钮。
5. **展开状态**：默认折叠；`activeProjectId` 变成某项目时自动展开它；手动切换持久化在 `appSetting.shell`（与侧边栏宽度同处），重启后保留；已删除项目的 id 在加载时清理。
6. **新建项目入口**：展开态从顶部导航移到「项目」分区标题右侧的 `+`（`⌘⇧N` 提示徽标跟着移过去）；侧边栏收成图标栏（rail）时，图标栏里仍保留「新建项目」图标。没有任何项目时，「项目」分区仍显示标题与 `+`，并给一行「从文件夹新建项目」的入口。
7. **对齐**（P5）：分区标题、项目行、嵌套行、顶部导航共用同一套列：图标列与导航图标对齐，文字列与导航文字对齐；行高与导航行一致。
8. **悬停操作**（P6）：`⋯` 在悬停、键盘聚焦、菜单打开、以及该项目为当前项目时可见。
9. **文案**：`shell.projects.home` 由「主页 / Home」改为「对话 / Chats」语义（键名随之改为 `chats`），新增分区标题「项目 / Projects」、空项目提示、开关的无障碍标签；zh-CN 与 en-US 同步，`translation-coverage.test.ts` 通过。

## Notes

- **已知限制（本任务不修）：展开状态会被云同步覆盖。** `appSetting` 整份参与云同步，`shell.expandedProjectIds` 跟着一起推送、拉取；但里面是本机项目的 id（`randomUUID()`，项目本身不跨设备同步），换到另一台设备毫无意义。拉取到另一台设备的设置时，本机的展开状态可能被对方的 id 顶掉，本机文件夹全部收起；下次项目列表刷新时 prune 把这些外来 id 清成 `[]` 写回，这个空列表又会同步出去，把对方的文件夹也收起。修法是在主进程同步投影里排除这个字段、拉取时保留本机值（参照 `modules/sync/index.ts` 对 `omitMainOwnedAuthSettings` / `preserveMainOwnedAuthSettings` 的用法），属于主进程改动，超出本任务「展开状态只是渲染层偏好、不改主进程接口」的范围。
