# 研究：uiarc.dev Dock「融合托盘」的实现手法（2026-09-25）

来源：ego-browser 打开 https://uiarc.dev/ ，滚到 Examples 里的 Dock 卡片（`aria-label="Dock"`），读 DOM 与运行时状态。uiarc 是付费组件库（卡片带 Pro 标记），此处只记录**技术手法**与观测数据，不摘录其源码，实现一律自研。

## 观测

- Dock 外形是一个 `<svg class="dock_surface…" width="286" height="56">` 里的单条 `<path>`，没有任何 SVG 滤镜（页面上 `filter` 元素数为 0）。
- 静止态 `d`：`M22 0 L264 0 A22 22 0 0 1 286 22 L286 34 A22 22 0 0 1 264 56 L22 56 A22 22 0 0 1 0 34 L0 22 A22 22 0 0 1 22 0 Z`——一个 22px 圆角的矩形。
- 点开「形状」工具后，路径的上边在托盘位置插入一段凸起（坐标里 y 为负，即向上）。托盘完全展开时这一段是：
  - 从主体上边走到托盘左侧前 12px 处，用二次贝塞尔**凹角**（半径 12）拐上去；
  - 竖直上升到离顶 20px，再用二次贝塞尔**凸角**（半径 20）拐到托盘顶边；
  - 顶边、右侧对称下来，最后以凹角回到主体上边。
  - 托盘高 52px；展开中途的采样里，凸起宽度从约 45px（与触发按钮同宽）长到 178px。
- svg 元素 `filter: drop-shadow(oklch(0 0 0 / 0.45) 0px 12px 28px)`：阴影跟着整条路径走。
- 托盘内容是一个绝对定位的 `div`（`width: 178px`），`opacity` 随托盘高度过半后才从 0 升到 1，`transform: translateX(...)` 跟随托盘中心；子按钮各自以 `opacity / y / scale` 错落入场。
- 驱动：托盘高度、托盘中心、托盘宽度各是一个弹簧值，每帧用这三个值重算 `d`（framer-motion 的 motion value → 派生路径字符串）。凹角半径随高度收缩为 `min(12, 高度 / 2)`，托盘中心被夹在「主体圆角 + 凹角 + 半宽」之内，所以永远不会压到主体圆角。
- 提示标签（悬停工具时出现）入场 / 出场用 `opacity + y + filter: blur(...)`，这就是截图里「模糊融合出来」的观感来源之一。

## 结论（对 TxFusionSurface 的影响）

1. 「融合」完全可以用解析几何得到，不需要 goo 滤镜；这样边缘锐利、能带阴影与描边、开销只是一条 path 的重绘。
2. 需要的参数就是「沿边中心 / 宽度 / 外凸高度」三个弹簧 + 两个半径（凹角、凸角）+ 夹边规则。
3. 内容层与外形层分离：外形是 svg，内容是普通 DOM，按进度做透明 / 模糊过渡。
4. uiarc 只有「长出」，没有「分裂」；分裂（颈部收腰、断开、残留回缩）是本组件为发送动画新增的能力，需要自己设计几何（见 design.md §2.3–2.4）。
