# 剪贴板历史详情页版式重排

父任务。承载需求来源、任务地图与跨子任务的验收标准；本身不直接实现。

## Goal

重排 `plugins/clipboard-history` 管理页：消除内容复述、把纵向空间还给有效信息，并把「只有文本/图片/文件三类 + 无差别拆词」升级为「按内容形态分类 + 按内容形态给洞察」。

## 需求来源（用户原话）

1. 「类似于这种可以优化一下拆到下面」—— 短文本被选中时顶部预览占半屏、下方标题又复述一遍。
2. 「看不清 被挡住了 每一个列表要展示图片缩略图」
3. 「右侧信息太密了 部分可以收纳到一个高级选项里」
4. 「还要支持图片 文本 视频 颜色 apikey 等等 最好可以有一个分类 用户可以快速选择」
5. 「这个拆词明显不合理吧」—— 一条 URL 被拆成 `dsh / web / https / com` 和 81 个字符格。
6. 「图片主题色」「如果复制了 #abcdee 这种也要展示颜色」

方案选择：用户在两个方案中选定 **方案 A —— 保留预览区，改为高度自适应**（而非取消独立预览区）。

## 全局约束

- CoreBox 宽度固定 `COREBOX_WIDTH = 720`（`apps/core-app/src/main/modules/box-tool/core-box/window.ts:45`）；插件 webview 挂在 56px 头部**之下**，插件渲染不到头部。
- 分类、洞察全部由现有数据派生，**不新增数据源、不改 transport 契约、不动主进程 clipboard 模块**。

  > **例外：C5 文件预览。** 已核实 `tfile:` 白名单（`local-file-policy.ts`）不含 `~/Downloads`——这是 #914 修复「渲染进程可读 `~/.ssh/id_rsa`」时故意收窄的；插件 SDK 也没有通用文件读接口。所以点击预览必须新增一个主进程能力，设计上以「API 不接受路径参数、只接受 `(recordId, fileIndex)`」保证不重开那个口子。详见 `09-05-file-preview/prd.md`。

  「视频缩略图」仍排在本次范围之外。
- 键盘契约不变：`↑/↓` 选择、`Enter` 粘贴到当前应用、`Cmd/Ctrl + Enter` 复制。
- 既有测试不得靠放宽断言变绿：`ClipboardActionBar.test.ts`（`apply-button` 文案含「粘贴到当前应用」；四个按钮的 pending 文案）、`ClipboardManagerView.test.ts`、`clipboard-items.test.ts`。

## 任务地图

| 子任务 | 交付物 | 依赖 |
| --- | --- | --- |
| C1 版式骨架 | 分类条、三段高度契约、列表行、文件树、底栏 | 无 |
| C2 内容形态分类器与洞察路由 | `classifyClipboardItem` + 洞察择一 | 无（可与 C1 并行） |
| C3 颜色能力 | 色卡、四格式、对比度、图片主题色条 | C2（需要 `color` 形态判定） |
| C4 更多信息折叠区 | disclosure + 折叠态持久化 | C1（需要详情区新结构） |
| C5 文件预览 | 主进程预览能力 + 图片/文本/Markdown/代码/PDF/3D 渲染器 | C1（👁 按钮由 C1 产出） |
| C6 记录分享 | 底栏分享动作，落在现成 CloudShareSDK 上 | C1（底栏样式）、C2（密钥判定） |

C1 与 C2 可并行；C3 在 C2 之后；C4、C5、C6 在 C1 之后。**C5 单独排期**——它是唯一改主进程的，安全边界需要独立评审。**C6 有开工前阻塞项**——`publish` 返回值里没有 URL，分享链接形状必须先和服务端确认。顺序写在各子任务的 `implement.md`，不靠父子关系隐含。

## 跨子任务验收标准

- [ ] 同一段内容在详情面板只出现一次；纯文本列表行的标题与副标题文本不相等。
- [ ] 720×540 视口下，切换文本 / 链接 / 图片 / 文件 / 颜色五类记录，预览区与详情区之间不出现空洞，留白只落在详情区末尾。
- [ ] 分类条 9 项在 720 宽下不横向滚动；点任一分类，列表结果与该分类定义一致。
- [ ] 复制 `#ABCDEE` 后，该条记录出现在「颜色」分类下，详情预览是色卡，洞察区给出 HEX/RGB/HSL/OKLCH 与对比度。
- [ ] 选中一条 URL 记录，洞察区是链接结构而非字符网格；含 `token` 的参数默认掩码。
- [ ] `pnpm --filter @talex-touch/clipboard-history-plugin test` 与 `typecheck` 通过，且四个测试文件的断言未被放宽。

## Out of Scope

- 视频首帧缩略图与时长（需要新增取帧能力）。
- 重复内容合并（×N 徽标）——设计稿已画出示意，实现另开任务。
- 敏感内容自动过期、文本快速转换栏、富文本双粘贴动作、⌘1..⌘9 分类快捷键。
- 浅色主题专项调优（沿用现有 `--clipboard-*` 变量映射）。
