## 2. 边缘不缓存这些静态文件

同一时段 curl，各取两次：

| URL | cf-cache-status | cache-control |
|---|---|---|
| `/_nuxt/r34uyRku.js` | MISS → HIT (age 5) | `max-age=31536000, immutable` |
| `/_nuxt/entry.BGUfteTF.css` | MISS → HIT | 同上 |
| `/en/docs/dev/components/button` | DYNAMIC / DYNAMIC | docs 规则 |
| `/en/docs/dev/components/button.md` | DYNAMIC / DYNAMIC | docs 规则 |
| `/api/docs/navigation/en/all` | DYNAMIC / DYNAMIC | docs 规则 + `etag` |
| `/api/docs/page/en/body/dev/components/button.json` | DYNAMIC | docs 规则 + `etag` |
| `/_i18n/ee31a2b9/en/messages.json` | DYNAMIC | `max-age=3600, s-maxage=86400, swr=604800` |
| `/en/docs`（根） | DYNAMIC | `max-age=0, must-revalidate`（Pages 默认；`/en/docs/*` 模式不匹配根） |
| `/` | DYNAMIC | `max-age=0, must-revalidate` |

静态 HTML 的服务端等待（ttfb − tls）在 0.26 s ～ 3.2 s 之间摆动；TLS 握手 0.2 s ～ 6.1 s。

原因：Cloudflare CDN 默认只按扩展名缓存（js/css/图片/字体等），HTML、JSON、无扩展名路径不在名单内，`_headers` 里的 `s-maxage` 在边缘无效，需要 zone 级 Cache Rule（Eligible for cache）。参考：
- https://developers.cloudflare.com/cache/get-started/
- https://developers.cloudflare.com/cache/how-to/cache-rules/settings/
- 免费套餐 Cache Rule 不生效退回 Page Rule 的案例：https://dev.to/doodoolove/why-cloudflares-free-plan-cache-rules-dont-cache-your-html-and-the-page-rules-fix-that-does-24d4
