# touch-image

`touch-image` 是官方隔离图片处理插件。它只接收宿主为当前生命周期签发的单个不透明图片令牌，可快速修改分辨率、压缩并导出 PNG、WebP、JPEG 与 ICO。

- 插件不读取、保存或展示原始图片字节、源路径或输出路径。
- 转码、尺寸限制、格式限制和保存对话框全部由受限宿主能力处理；Sharp 在可终止 Worker 中运行。
- 每个动作均在调用前校验当前生命周期与签发令牌；过期、伪造或跨插件动作会被拒绝。
- 查询可选 `WIDTHxHEIGHT`（每边 1–8192、总计不超过 6400 万像素）和 `q1..100`；PNG 始终无损优化，质量参数用于 WebP 与 JPEG；ICO 接受 1–256 的方形单尺寸，其他尺寸使用标准多尺寸图标集。

开发验证：`pnpm -C plugins/touch-image test`
